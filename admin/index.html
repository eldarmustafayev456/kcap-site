KCAP · Редактор контента

Тексты, проекты и новости можно менять в полях ниже. Сохранение подготовит файл обновления. Загрузите его в папку content репозитория KCAP, сохранив имя файла; после подтверждения изменений GitHub пересоберёт сайт.

Этот редактор не отправляет данные на сервер. Для загрузки обновления нужен доступ владельца репозитория. Не добавляйте конфиденциальные материалы. Публичный репозиторий содержит и историю изменений.

Открыть контент в GitHub ↗

Статус «черновик» исключает запись из выпуска. «Избранный проект» добавляет её на главную. Перед публикацией заполните EN, 한국어 и RU; корейский текст направьте Сергею на вычитку.
